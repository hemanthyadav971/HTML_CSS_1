# Bella Tavola - Artisan Italian & Mediterranean Restaurant

> **Creative HTML & CSS Webpage Project (Group 1 - Project 2: Restaurant Website)**  
> Built strictly using **pure HTML5 and CSS3** (no JavaScript or other programming languages).

---

## 📋 Features

- **Hero Section**: High-impact visuals, value proposition, quick booking & menu CTA buttons, and key restaurant stats.
- **Our Story / Heritage**: Farm-to-table philosophy, wood-fired oven highlights, and cellar details.
- **Curated Menu**: Categorized seasonal dishes with badges (Chef's Pick, Bestseller, Vegetarian), pricing, and descriptions.
- **Special Offers**: Eye-catching promotional banner for tasting menus and discounts.
- **Customer Reviews**: Testimonials from food critics and diners with 5-star rating presentation.
- **Table Reservation Form**: Fully styled, accessible reservation form with guest count, dates, and special requests.
- **Contact & Location Details**: Physical address, opening hours, contact details, and footer navigation.
- **100% Responsive Design**: Optimized for mobile, tablet, and desktop viewing.

---

## 🛠️ Built With

- **HTML5**: Semantic tags (`header`, `nav`, `main`, `section`, `article`, `footer`, `form`).
- **CSS3**: CSS Grid, Flexbox, custom CSS variables, Google Fonts (`Playfair Display` & `Plus Jakarta Sans`), responsive breakpoints, and smooth micro-interactions.
